# GCOMGv2.1-FSS：期望撮合评分 + 可选策略探索

本版本保留 GCOMGv2 的期望收益规则、逐策略反事实订单簿、有限 `r`、有限 `T`、FSS 显式/隐式表示、价格形成和公共信息更新。**不加入 score redistribution。**

唯一新增机制是可选的 epsilon-greedy 策略探索：每轮每个 agent 以概率 `epsilon`，从自己持有的 `s` 个策略中均匀随机选择一个；否则选择当前分数最高的策略。它不直接翻转买卖动作，也不增加策略池。

默认 `--strategy-exploration 0`，因此与原 GCOMGv2 一致。推荐实验参数可显式设置为 `0.005`。

## 推荐的初始诊断命令

```powershell
python .\gcomg_v2_1_fss.py --N 501 --m 4 --s 2 --T 20 --r -0.04 --L 0 --lambda 5010 --x0 100 --price-mode linear --initial-score 0 --strategy-exploration 0.005 --steps 10000 --seed 1 --burn-in 1000 --outdir run_v21_seed1
```

建议再将 `--seed` 改成 `2`、`3` 重复，不能只看一个随机种子。

## 参数解释

- `N=501`：保留奇数规模以便和原实验比较；但奇数规模会允许 `D=+/-1` 的自洽锁定态。可把 `N=500` 作为对照，不应认为改偶数就完全解决锁定。
- `m=4`：公共信息记忆长度。信息是滚动的需求符号历史，不是价格本身或 `(x,M,n)`。
- `s=2`：每个 agent 持有两个策略。
- `T=20`：有限分数记忆时间。
- `r=-0.04`：负的有限入场阈值。当前 `L=0` 下期望得分非正，正 `r` 很容易造成参与衰退。
- `initial-score=0`：避免沿用旧 GCMG 中 `r+10` 的大初始分数偏置。
- `strategy-exploration=0.005`：每轮约 0.5% 的 agent 随机从自身策略集中抽取一个策略。因随机抽取可能恰好抽到原本的最佳策略，实际改变策略选择的概率低于 0.5%。
- `lambda=5010=10N`：保持原有数值深度约定。
- `price-mode=linear`：先控制价格漂移；只有当需求均值足够接近零时，再比较 log price mode。

## 解释边界

探索项是一个明确新增的行为假设，用来打破当前 GCOMGv2 的策略排名冻结态。它并不自动产生真实市场的长记忆波动聚集。若 `ACF(|r|)` 在中长滞后仍接近零，下一步需要考虑有持续性的活动/订单流状态，而不是继续只调 `r,T,lambda`。

## 输出

CSV、价格/活跃人数/收益分布/ACF 图、价格增量分布图和 JSON 汇总。汇总新增 `ACF(|r|)` 的 20、50 阶，以及活跃人数的 1、5、10 阶自相关。
